# Mise à jour GitHub — Hoenn CE2

1. Décompressez l’archive.
2. Ouvrez votre dépôt avec GitHub Desktop.
3. Cliquez sur **Repository → Show in Explorer**.
4. Remplacez les fichiers actuels par le contenu de l’archive.
5. Ne supprimez pas le dossier `assets`.
6. Revenez dans GitHub Desktop.
7. Saisissez comme résumé : `Ajout Hoenn CE2`.
8. Cliquez sur **Commit to main**.
9. Cliquez sur **Push origin**.
10. Attendez le déploiement GitHub Pages puis rechargez avec `Ctrl + F5`.

La progression Kanto et Johto enregistrée dans le navigateur est conservée.
