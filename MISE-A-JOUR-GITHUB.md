# Mise à jour GitHub — PokéClasse 1.5.2 finale

1. Décompressez l’archive.
2. Ouvrez votre dépôt dans GitHub Desktop.
3. Cliquez sur **Repository → Show in Explorer**.
4. Remplacez les fichiers actuels par tous les fichiers de cette archive.
5. Revenez dans GitHub Desktop.
6. Vérifiez les fichiers modifiés.
7. Dans **Summary**, écrivez : `Version finale 1.5.2`.
8. Cliquez sur **Commit to main**.
9. Cliquez sur **Push origin**.
10. Attendez le déploiement GitHub Pages puis rechargez votre site avec `Ctrl + F5`.

La sauvegarde normale utilise `pokeClassV2`, donc la progression existante reste conservée dans le même navigateur.
